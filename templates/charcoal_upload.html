Charcoal drawing

Turn photographs into charcoal drawings. Tune the look on the first image, then process them all into a charcoal/ folder.

Pick one or many images (Cmd/Ctrl-click or Cmd/Ctrl-A to select all in a folder).

…or choose a whole folder

Every image in the folder is loaded; non-image files are ignored.

Used only for AI charcoal (Google Gemini). Claude/Anthropic has no image-generation API, so it can't produce these drawings.
